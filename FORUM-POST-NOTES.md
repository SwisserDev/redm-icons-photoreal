## Before posting

Trust level 1 is required, and only one release every 48 hours. With 8 styles
that is a campaign of about 16 weeks, one post every other day. That spacing is
an advantage rather than a nuisance: each post is a fresh appearance in the
category, which is exactly how the biggest paid vendor there built its reach.

## Copying

Paste from the raw markdown, not from a rendered preview. VS Code puts a
syntax-highlighted HTML copy on the clipboard by default and Discourse prefers
it, which escapes the markdown and shows the asterisks as text. Either use
Ctrl+Shift+V when pasting, or set `"editor.copyWithSyntaxHighlighting": false`.

## Images

The 13 category cards are embedded as raw GitHub URLs, so they need no upload.

**The hero is the exception.** Drag preview/hero.png into the editor by hand at
the very top, replacing the placeholder line. Discourse builds the topic-list
thumbnail only from an attached image, so a linked hero leaves the thread
without a preview in the category listing.

## Order of release

Lead with the style that has no competition rather than the crowded one.
Photoreal competes with two existing free packs; outline, minimal, monochrome
and retro have no dedicated pack at all in the category.
